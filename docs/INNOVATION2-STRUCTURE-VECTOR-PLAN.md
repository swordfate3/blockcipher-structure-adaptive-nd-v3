## 1. 为什么推进，不再追人工95%

[人工机制检查](INNOVATION2-STRUCTURE-VECTORS-RESULTS.md)向量图TEST87.11%、null49.41%，是部分人工泛化证据；未过旧99/95门槛，不等于方法应淘汰。
旧门槛是人为“接近完整组合”筛选，未按样本/优化或下游用途校准，不能当真实密码探索必要条件。
本批直接检验：公开目标DAG上的多通道乘性交互，在固定未知key六轮绝对bit0任务上是否出现真实DEV改善。
不用人工准确率作为预定性能预测；不声称已有文献证明六轮可学。

三个候选已比较于[设计](INNOVATION2-STRUCTURE-VECTORS-DESIGN.md)：标量软图历史不稳定/未拟合；有限奇偶字典未检出稳定信号；本次选择类型化向量图。
相对CNN：固定完整计算路径、AND/XOR分工、只目标节点读出；相对软图：不在每门压成标量概率；相对轮展开：不以小MLP一次学习完整局部轮函数。
这不是首次用公开结构或首次多通道；历史两轮向量曾不如标量，不能仅凭向量命名承诺优势。

## 2. 明确模型（只此一个）

`model_kind=simon-vector`，仅prediction/simon/full/direct、rounds6/bit0/width32；构造器/配置严格拒绝其他组合，不预建更多轮数/宽度分支。
公开`SimonCone`406节点（56明文叶/70符号轮key效应/70AND/210XOR），最长24个二输入门，保留共享子式/符号绑定。
仅根据公开深度与门类型分组执行，结果等同逐节点拓扑计算，不改函数依赖。全文明文接口[N,64]，图读取保守支持56位，其余8位不影响输出。
每个明文叶为[1−2bit,0,...,0]，符号叶为TRAIN学习的样本不变32维向量，不接收真实key或状态。

两种门各自共享：

    z = A(a+b) + B(a⊙b) + C[(Ua)⊙(Ub)] + β
    h = z / max(1, ||z||₂ / 2)

输入交换对称。未知叶同样半径2投影。内部不是概率，无sigmoid，无真实中间监督、自由节点ID embedding、结构指纹condition或全局flatten旁路。
只目标节点向量经32→1输出raw logit；最终BCE监督、Adam/clip1、DEV选模沿用统一训练。

### 数值约束为何这样改

人工原型深层幅度到4257，故在正式科学拟合前明确新增逐节点L2球半径2投影。
这是**新参数化/新版本**，不宣称其继承人工87%成绩。
与全向量LayerNorm不同，范数≤2时完全不变，因此精确符号Boolean编码[±1,0,...]的AND/XOR表达见证保留。
投影限制前向激活，不限制参数/投影前中间值，不保证梯度不衰减、不爆炸或能找到正确规则；边界有不可微点，区间内部/外部差分分别检查。
半径2是留出单位符号编码余量的固定工程选择，不是已证明最优；本批不扫半径。
初始化与人工原型一致的近平均线性路径/小乘积路径/随机常量，不装入真实或旧解；本批无精确门初始化/STE。

参数 **8d²+73d+1=10529**（d32）；包含70×32未知效应向量，不是70独立主key比特；不约束完整key schedule，因此模型族宽于合法主key函数族。
批256的一份406×32节点表约12.69MiB，分组拼接/反传缓存额外占用；不是峰值显存或GPU速度保证。
只用Torch，不加图学习依赖/运行服务。

## 3. 模块边界与不变行为

- `representations/simon_vector.py`：公开目标图的levelized计划，无秘密/样本/标签或Torch依赖。
- `models/simon_vector.py`：投影、两个共享单元、动态向量计算，只读明文与公开图，输出单logit。
- config/factory/checkpoints/report最小接入；checkpoint保存schema不变，严格加载后重新生成并核对全部持久路由/坐标/输出索引。
- report只读元信息，不额外前向/标签/训练；不往通用training/evaluation/CLI堆专属运算。
- 旧模型/密码/采样/标签/优化/选模/TEST时序/创新1不改；无registry/新runner/旧远端任务包。

## 5. 如何评价：不再拿95%当任意科学门槛

每项最低DEV BCE选best，平局最早；全报8个DEV机会，不按TEST改候选。null也按相同DEV规则。
主观察：真实selected DEV BCE与TRAIN常量比较，同时报告ACC相对常量/null的差值，TRAIN拟合、末在线TRAIN/DEV分别记录。
描述“值得独立确认”的探索线索仅在真实DEV BCE更低、DEV ACC同时高于常量及null时成立；这只是预定描述性规则，不称显著性或推广证明。
不把55%/3pp/95%搬成通用成败定律；任何小差异都应报告有限样本误差与单seed限制。无差异或反向也完整保留，不据此证明不可能。
为避免事后最高分选择，主候选仅一个；即便出现线索，也不能自动追加确认预算，须新面板/明确效应与不确定性协议。

TEST当前CLI自动生成/保存/输出，非技术封存；外层先记录TRAIN/DEV决定再展示TEST，完整JSON字节可能已读取，如实记录。
TEST只作为该冻结探索结果的旁证，不反过来选择模型/预算。接收只核SHA/身份/JSON聚合/退出，不加载权重、再生科学标签或做新前向。

两项不是结构归因实验：没有匹配非结构模型同期对照；历史CNN不能用于因果比较。即使改善，也只说候选有信号，不说收益必然由结构或向量产生。
