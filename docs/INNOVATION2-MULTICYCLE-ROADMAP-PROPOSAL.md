## 1. 最终问题、阶段产出和不做的事

### 1.1 原始主问题

在SIMON64/128固定未知key下，模型只读一个明文及公开结构，能否预测未见完整随机明文的预定绝对密文bit？默认主目标固定C0，优先六轮，条件推进八／十轮。

完整算法44轮；六、八、十轮是约化轮数，不写成完整密码破解。实际key／轮key／内部状态／其他密文bit教师不得进入模型。学习TRAIN中的未知key效应允许，但不能把实际秘密注入模型。

### 1.2 三种终点必须分开

1. **预测阳性**：冻结候选，在明确轮数／分布上胜过TRAIN常数及适用公开参考，且在新面板、新初始化上确认；非D候选若另胜同期D，才主张方法相对优势。D本身获选不与自己比较，只能确认直接基线的预测能力；单独说明第二把key的结果。
2. **积分阳性**：明确输入cube、目标位和量词，得到非平凡的高轮零和充分证据及可核查可信链；不是神经泛化。
3. **完整阴性／不确定交付**：有固定候选族、计数、对照、失败原因和边界，回答当前方法为何不晋级；不是科学阳性，但不能为追求阳性无限扩大预算或改指标。

**不能承诺“不断试直到必有高分”。** 目标是提高得到可靠阳性的机会，并在没得到时仍能交付可复核的方法结论。未达终点时按本稿停止，不自动进入第二轮无界搜索。

### 1.3 明确不做

- 不随机加网络、表达式、seed、数据量、训练时长或输出位。
- 不重跑已关闭的496个八轮高字k2反例扫描。
- 不训练恒零积分标签后报告100%神经成功。
- 不把子空间高分、低轮正控、公开表达见证或非零梯度当作高轮成功。
- 不借测试名义无界调用生产encrypt；工程调用和正式调用分别累计。
- 不创建通用workflow／registry／自动远程编排，不在训练层堆候选算法或分析报告。

## 4. 神经主线：四阶段、最多36 fits

### 4.1 共同固定规格

- 每fit：TRAIN65536、DEV8192、TEST65536；pool65536；batch256；32epochs；Adam lr.001、clip1；每epoch DEV最低BCE选模、平局最早。
- 每fit最多8192更新、2097152训练呈现、32次DEV机会；每real fit139264次encrypt，null同量随机bit。每个run独立造标签，除非另行设计缓存，不扣除重复调用。
- 相同阶段配对臂共享输入身份、标签、shuffle和预算；跨形状模型不以同seed声称初态相同。
- 相同seed不保证跨历史／跨run数据不重叠。新面板选择规则只依赖无标签明文，先验去重核对并冻结，禁止看输出挑面板。
- 数据／init／第二把key的具体seed在设计版统一列出；当前不虚构已冻结编号。
- 本路线不靠学习率／宽度网格；模型尺寸与正则强度在编码前冻结。

### N1：背景敏感性的机制控制，最多6 fits

**问题**：标签仍是三轮C0 XOR C8，真实高半仍固定B=0xA5A5A5A5，只改变模型输入表示，区分固定输入通道与目标函数差异。

| 臂 | 标签侧明文 | 模型侧输入／初始化 | runs |
|---|---|---|---:|
| R | [B,L] | 原始[B,L]、常规初始化 | real/null各1 |
| Z | [B,L] | [0,L]、与R同参数初态 | real/null各1 |
| M | [B,L] | [0,L]，首层bias补入初始W_fixed·bits(B) | real/null各1 |

M只用公开B和初始参数，确保在该空间上与R初始函数一致；不保证Adam后续轨迹一致。R/Z参数一样但函数可能不同。必须分别核参数身份和初始输出等价，不能混为一谈。

- 明文采样和标签不变；禁止把归零后的输入用于encrypt。
- 本阶段是有限低轮机制实验，不追加背景、不降到一／二轮、不扩表达式。
- 输出：selected TRAIN/DEV、在线TRAIN、逐样本预测／配对指标、正类输出比例及logit摘要。
- 实际重要性建议：较R的DEV ACC至少+3pp且BCE至少−.01，作为解释历史40.8pp落差的筛选门槛；这是研究价值选择，不是理论阈值或显著性证明。

**分支**：

1. Z/M均改善：支持输入参数化／优化参与，但不声称解释全部差距。
2. 仅Z改善：初始函数改变仍是关键替代解释。
3. 均不改善：本预算下无明显归零收益，保留目标差异与其它优化解释。
4. null出现异常预测、身份错、初始等价失败：先停做工程诊断，不启动N2；正式错误不自动重跑。
5. 工程有效但机制阴性：仍可进入N2，因为full任务没有固定半，N2不是由“归零成功”才能成立的假设。

N1结论是探索性的，本稿不为它追加独立确认；若最终以此作为核心论文贡献，需要另立确认合同。

### N2：六轮full的有限结构方法比较，最多10 fits

主目标回到**完整随机明文→绝对C0**，不继续xor2追分。

公开坐标Z=phi(P)=(Y XOR F(X),X)。固定字典：

Psi(P)=[Z, Z_H[(i+1) mod32] AND Z_H[(i+8) mod32], i=0..31]。

共96维，保留全部64位可逆坐标，增加32个公开二元交互；不包含实际状态／key。假设是显式布尔组合能降低发现成本，**不是已有有效性或新颖性证明**。旧坐标实验阴性和旧64奇偶mask阴性必须并列说明。

另定义q_r(P)：r轮公开递推、所有轮常量均置0的目标bit。残差候选返回绝对logit (1−2q_r(P))g(P)。r>=5时它不是零主密钥SIMON加密，不得偷改现有1..4轮public_reference语义或命名。

| 候选 | 输入／读出 | 用途 |
|---|---|---|
| D | 原始64位MLP | 同期直接基线 |
| F | 96维字典MLP | 公开特征的独立作用 |
| R | 原始64位MLP＋q6符号恢复 | 公开参考的独立作用 |
| FR | 96维字典MLP＋q6符号恢复 | 主组合候选 |
| S | 同字典97参数L1线性logit＋q6符号恢复 | 判断字典信号与神经组合增益；不是额外网络调参 |

每候选real/null各1，总10。L1系数需在设计阶段固定单值，不进行正则扫描；若引入稀疏头，目标函数／优化计数单列，不声称与无正则MLP完全同训练目标。

width128：原MLP24961参数、96维MLP29057参数，S97参数。表示与容量不完全匹配，不能从F胜D直接下纯表示因果结论。计算粗估MLP每batch O(B(dh+h²))，q_r为O(32rB)布尔操作；实际吞吐未知，工程先测，不用历史耗时担保。

**对照与选择**：

- 除TRAIN多数／常数概率，所有候选对比q6＋TRAIN残差常数；它的拟合与评估计量，不算神经fit。
- 各臂最低DEV BCE选checkpoint；跨候选只按DEV选择。TEST自动输出事实透明披露，但不参与选型／扩预算。
- 提议实用晋级门槛：DEV ACC较TRAIN多数至少+2pp、相对最强适用常数／公开参考的BCE改善至少.005，且候选不呈现对应null中的同类收益。
- .005／2pp是待批准的研究价值门槛，不是Bayes界或显著性阈值。不能只用“比null高”忽略同标签强基线。
- 想主张神经方法创新，还需FR/F/R胜过S和D；若S一样好或更好，简化为公开特征预测研究，不硬称神经突破。
- 通过者按DEV BCE排序；数值平局时先参数少、再固定候选ID顺序。若D胜出，结构假设失败，但可确认同期基线，不重复训练相同候选。

**分支**：

1. FR通过且有增益：冻结FR。
2. F/R足够好、FR无额外收益：选更简单通过者，删去无收益组件的主张，不删除历史代码／证据。
3. 只有S通过：冻结S，结果明确不是神经成功。
4. 只有D通过：冻结D；结构机制不获支持。
5. 全部未通过／微小方向冲突：神经探索停止，N3/N4不启动，不追加CNN／Transformer／seed。
6. 严重负控异常／身份错误：工程阻塞，不把错误当科学阴性。

### N3：固定候选高轮推进，最多8 fits

前提：N2至少一候选通过，结构／优化参数全部冻结。每轮4 fits：候选real/null＋同期D real/null。

资格分两层：预测能力资格＝通过常数／公开参考的N2实际效果门槛；方法优势资格＝非D候选除前者外，相对同期D的DEV BCE再改善至少.005、ACC不下降。D候选只判断预测能力，不作自比较。N4默认优先确认最高具有方法优势资格的轮数；若从无方法优势，则确认最高具有预测能力资格的轮数，并收缩方法创新主张。高轮只有预测能力、低轮有方法优势时，不让高轮抢占低轮的唯一确认预算，两者均完整报告。

1. 首先八轮full C0，4 fits。
2. 八轮满足与N4目标主张一致的资格后，十轮full C0再4 fits；对非D候选默认要求方法优势资格，若仅有预测能力则不晋级十轮。
3. 八轮失败：十轮不启动，保留六轮候选进入N4；十轮失败：保留八轮候选进入N4。
4. 只比较同轮候选与同轮基线，不能把不同轮准确率直接解释为方法因果收益。
5. 若N2选择D，N3每轮只需D real/null，不能复制相同候选骗取对照数，节余不改投其它方法。
6. 若资源／执行UNKNOWN，不跳到更高轮；已知有效的低轮候选可在确认前审查后进入N4。编码错误可能污染共用实现时，先降级全部受影响候选。

这一阶段不是完整逐轮安全边界扫描；只检验预声明六→八→十轮阶梯，不临时补七／九轮或扩大epoch。

### N4：冻结最高合格轮数后的独立确认，最多12 fits

按N3的双层资格规则固定候选／轮数／分布／优化协议，三个确认块，每块最多4 fits：候选real/null＋D real/null。确认目标是“预测能力”还是“方法相对优势”必须在启动前写明，不能结果出来后切换。

- K1：原key，新明文面板、新init。
- K2：原key，另一新面板、新init。
- K3：第二把key，新面板、新init，从零重新训练；不是旧模型跨key迁移。

若候选为D，去掉重复D和全部对D的自比较；不得将节余用于补seed。若候选为神经FR/F/R，还应在解释中对照N2的S；本矩阵不包含S新确认，因此**既不能声称确认了原key上神经相对S的可重复优势，也不能声称确认了跨key相对S优势**。若该主张是论文核心，应在设计阶段以S替换部分D对照或增加明确预算，不事后补实验。

**确认指标建议**：

- 同一TEST上的候选对TRAIN常数、适用公开参考的ACC／BCE改进；非D候选再加入同期D比较。使用实际逐样本保存预测，接收端不加载模型重算。
- 预测能力主确认量为相对每块预先声明最强常数／公开参考基线的平均BCE改善，同时要求实际效果（建议.005 BCE／+2pp）。非D候选的方法优势另要求对D的BCE改善至少.005且ACC不下降，并检查配对区间；D候选删除该比较。不只报p值，也不把未确认的方法优势当成预测能力失败。
- 区间方法在设计阶段冻结：优先逐样本配对bootstrap 10000次，保存随机种子与重采样定义；对确认块×预声明比较族做Bonferroni区间。bootstrap是近似抽样推断，不声称分布无关严格保证。
- BCE若为数值稳定诊断而截断概率，须另名、声明阈值，原始BCE仍保留；不得看结果后选截断值或改主指标。
- 三个块按固定协议全部收口后才作最终结论，单块阳性不改变后续配置。区间只针对给定已训练模型与样本，不覆盖所有seed／key不确定性。
- 当前CLI自动生成／输出TEST，无技术封存；确认性来自先冻结和全新面板、不反馈改模型，不声称访问强制隔离。若需要DEV-only属于独立公共行为变更，本稿不顺手实现。

**终点**：K1/K2均通过才称所测key的可重复结果；K3通过仅支持第二把已测key，非广泛跨key保证。部分通过＝不稳定／有限适用；全部失败＝降级探索阳性，不追加第四块，不把确认集回收成新开发集后仍称确认。

- 用人工Boolean／平方自由回代oracle、故意损坏门表／COPY、模型缺失／proof缺失／资源截断fake fixture验收。

**正控**：人工共享图＋已知六轮{0,4,10}、七轮{0,2}关系，以及已有八轮反例cube的抽象可达性。新抽象未必足够强复现每个旧充分证书；无法复现必须先区分抽象损失和编码错误，不拿高轮结果猜门表。

### I1：八至十一轮固定候选，最多16正式求解

这不是论文十一轮复现。Todo摘要未给出的维度／输入／输出规范一律不猜。

候选族提议：用公开置换顺序pi_(2j)=5j mod32、pi_(2j+1)=32+(5j mod32)，j=0..31，固定S_k为前k位置，k∈{16,32,48,63}；轮数8/9/10/11，目标始终高字MSB bit0。总16规格，正式前完整列出具体位集合并冻结。

- 选择这些集合是跨两字、有限维度覆盖，不是已有最优性／存在性依据；高维减少全体包含项是动机，但不保证适用抽象能证零。
- 每候选先做公开非平凡性筛查：非空、非全64位、活跃位均在目标cone内；缺失依赖、简单次数上界和已证cube超集标清。
- 同轮嵌套超集如继承已有零结论，跳过求解、标继承，不计独立发现。
- 若简单可靠的基线已证同样结果，仍可作工程对照，但不能以此声称新DP方法贡献；等成本比较基线证书能力与时间。
- 公式规模应随节点／使用端口线性，不含2^k复制；这不保证SAT或proof检查容易。

### I2：按结果分支，不把SAT当反例

| 结果 | 后续动作 | 结论上限 |
|---|---|---|
| SAT＋独立抽象路径检查通过 | 继续下一个冻结候选 | 抽象可达／该方法未证明，非真实不平衡 |
| UNSAT＋proof checker核原始CNF通过 | 再核图／编码／量词链，继续合同内更高轮 | 有条件的零和充分证据，不自动是文献新纪录 |
| UNSAT无可用独立proof | 只使用预留认证额度；不可用则停在未认证 | solver报告，不称已认证积分证明 |
| 单项资源UNKNOWN | 完整收口并计量；同轮连续两项资源UNKNOWN则关闭后续科学启动 | 当前资源墙，非安全证明 |
| 编码／路径验收／身份错 | 立即停，保留原件，降级受影响结论 | 工程错误，不自动重试 |
| 全16项无证书 | 关闭，整理抽象能力边界 | 不扩cube／输出位／轮数或换solver继续搜 |

轮常量按任意固定未知参数建模；若能证明则覆盖合法key调度。SAT不推出合法key反例，不把合法调度直接塞进指数模型并假称保留值域相关性。
