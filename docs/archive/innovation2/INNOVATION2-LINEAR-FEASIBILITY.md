# 六轮下一机制：公开Walsh／奇偶特征的可行性核查

## 当前目的与权限

在原MLP数据与计算六项均近随机后，用户说“继续”。本轮继续机制调查、数学推导与无标签工程验证，
不把该请求解释为新的科学拟合/GPU/SSH/安装或发布许可。六轮bit0仍是目标，不退回低轮追分。
本轮先问“能否从公开结构得到值得训练的特征”，而不是先选一个网络再盲跑。

假设：原ReLU MLP可能没有有效发现XOR／奇偶组合。用公开结构预先构造精确奇偶特征，再只学习最终线性logistic头，
可以绕过“靠深层梯度发现这些特征”的一部分困难。
这是待检验解释；已有真实/null类似的损失曲线不能单独证明奇偶是根因。候选特征未必包含实际固定key下的可学信号。
该路线接近经典线性密码分析启发的结构基线，不是已经实现神经轮组合学习，也不声称研究新颖性。
独立只读架构核查认为值得做小型频谱诊断、不值得立即大规模训练；本轮只实现无标签编译，
不采用其建议的不同筛选阈值作为已授权门槛，历史55%/3pp标准不被默默替换。
若后续采用频谱基线，它只能测试“选定公开表示里是否有可用信号”，不能替代创新2最终想要的神经组合学习；
不把改为显式符号key搜索、输出多bit或差分类任务当成解决原任务。

## Walsh字符与可辨别结论

对输入bit集合S，定义`chi_S(P)=(-1)^(XOR_{i in S} P_i)`；目标sign `z(P)=(-1)^C_j(P)`。
若总体相关`rho_S=E[z chi_S]`，选正确符号的单特征分类准确率为`(1+abs(rho_S))/2`。
因此55%单特征准确率要求|rho|≥.1。未知key只允许从TRAIN样本中学符号/系数，不读实际key值。
许多字符的线性组合可以优于任一单字符；反之单字符弱也不能直接给多特征模型准确率上界。

对于预先固定、有限M特征、理想独立均匀采样，Hoeffding+union bound给
`max_S |rho_hat_S-rho_S| <= sqrt(2*ln(2M/delta)/n)`，概率至少1−delta。
M64/n65536/delta.05时约.0155（相关单位），对应单字符优势约.77个百分点的不确定量级。
这是理想采样参考，不是实际伪随机数生成器的覆盖证明、不代替DEV验证，也不是训练线性组合的误差界。
若在TRAIN适应性生成更大字典或重复搜索，M必须计入完整搜索空间，不能仅数最后选出的64个。
本轮不读TRAIN/DEV/TEST标签，所以不存在本轮标签相关测量或相关性显著发现。

## 用公开轮结构产生候选：精确局部谱，截断全局路径

所有位置用MSB索引0..31。数学内部掩码bit i对应MSB坐标i，不同于把mask当SIMON数值字直接按bit i解释。
写输出线性形式`a·X_next XOR b·Y_next`，其中
`X_next=Y XOR F(X) XOR K_r`、`Y_next=X`。
内积`a·X`指在GF(2)中选定坐标的异或和；字符`chi_a(X)=(-1)^(a·X)`。
定义`q_a(X)=XOR_{i:a_i=1} X[i+1]X[i+8]`（索引mod32），旋转线性项掩码`rot2(a)`把位置i送i+2。
有精确恒等式：

```text
(-1)^(a·X_next XOR b·Y_next)
= (-1)^(a·K_r) * chi_a(Y) * chi_(b XOR rot2(a))(X) * (-1)^q_a(X)
(-1)^q_a(X) = sum_t W_a(t) chi_t(X)
W_a(t) = 2^(-m) sum_{x on active variables} (-1)^(q_a(x) XOR t·x)
```

故一步向后迁移`(a,b) -> (b XOR rot2(a) XOR t, a)`，局部系数W_a(t)，并记录未知key的符号坐标a。
局部只对参与q_a的m个变量完全枚举并整数FWHT；m≤12才计算，超过明确限额，不把截断称精确全局结果。
从预定输出bit0开始回推六步，无真实key取值、不执行密码标签生成。
保留至多64条按系数绝对值等公开规则确定排序的路径，超预算分支明确计数丢弃。

**单条路径系数不是实际固定key的相关、不是下界或完整线性包络。**
完整展开中同一明文mask的不同路径及未知key符号可能加强或抵消。
例如两个符号贡献`c*chi_k1(K)`与`c*chi_k2(K)`，在某些赋值下和为0、另一些为±2c；
单条贡献大小c本身不能作为实际总相关下界。这只是代数示例，不是本轮已求得真实key的hull。
有限beam可能遗漏更强项或全部信号。
即使局部AND输入相互依赖，完整局部谱可精确处理；仅乘被保留路径不等于解决多轮完整谱。
保留路径中的key符号只是公开占位，不能代入实际key/从旧解权重赋值；实际round-key schedule也不据此恢复。
最终仅将路径投影成去重明文mask作为待评估字典，没有把路径系数作为真标签或保证准确率。
实际key schedule关联只会约束这些未知符号的可能赋值，不能把它们当独立已知常量；本轮不计算真实schedule。
候选由固定输出bit0生成，不在看到结果后挑更有利输出线性组合或改预测任务。

## 为什么先核查而不立刻跑模型

- 全64位≤2阶字典已有2080个非空字符，≤3阶43744个；高阶目标不保证落在低阶，穷举2^64不可行。
- 现有公开依赖传播给六轮bit0共56个保守明文坐标，但依赖集合不等于相关mask，更不是最小ANF支持证明。
- beam字典大小小、可按目标公开结构选高阶字符，但也可能覆盖极差；必须先保存路径/剪枝统计。
- 若公开路径已经很弱，只能说明本特征候选理由有限，不能据路径弱断言真实hull弱；不自动加beam/选更有利目标bit。
- 无标签工程通过仅说明公式/位序/资源控制正确，不代表六轮预测有效。

只有在核查后仍有明确理由，才另定固定字典的`logit=b+sum(w_S chi_S(P))`候选。
固定特征下最终bit BCE对w,b凸，但固定步Adam不保证达到最优，也不保证泛化。
若后续提出拟合，应另外明确正则化、求解残差/未收敛判定与资源预算；本轮没有把新head接入训练系统。
采用绝对bit标签y和z=(-1)^y的符号约定时，零初始化的BCE梯度为
`dL/dw_S = (1/(2N))*sum_i z_i chi_S(P_i)`；不是通过深层软门的乘积，但也可能只有采样噪声。
若固定字典与目标的总体相关全为零且目标平衡，零head是凸logistic总体风险的全局最优；
该模型不会仅靠多训练就组合出字典外特征。一次null也不是完整经验零分布或显著性检验。
不先用真实标签挑mask，再用同一批标签声称独立确认；随机mask字典要匹配数量/重量并明确对照局限，real/null必需。
若候选不足以支撑训练，保存阴性可行性判断，不为“继续”自动启动GPU。
