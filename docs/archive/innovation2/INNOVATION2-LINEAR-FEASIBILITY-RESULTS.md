# 六轮公开Walsh路径：无标签可行性核查结果

## 决定：不直接启动新GPU拟合

按[事先固定的无标签核查](INNOVATION2-LINEAR-FEASIBILITY.md)，六轮bit0、beam64、局部变量限额12一次编译完成。
得到64条路径、64个不同明文奇偶mask，重量5..11，最大绝对路径系数**1/1024**。
这提供了一份可审计的公开特征候选，但**没有得到任何真实TRAIN相关性或DEV/TEST预测分数**。
目前不足以支持一次新的大规模神经训练；本轮停在编译/工程核查，不改模型/训练入口，不自动扩大beam/选更有利输出位。

1/1024是单条被保留路径的局部谱系数乘积，不是实际固定key的相关或上下界。
如果“假想只有这一项且无其他贡献”，单特征优势才会是1/2048≈0.04883个百分点，**该假设未被证明，不是预测结果**。
真实完整hull可能增强、相消，遗漏路径也可能更强；所以不能据此宣称六轮没有线性信号或此路线理论不可能。

## 实际编译统计

纯标准库`representations/simon_linear.py`：局部q_a完整有限枚举+整数FWHT、Fraction精确系数；
超12变量的输入路径明确剪去，beam最多64，最多6轮，每轮最多262144扩展。未合并路径为hull。
内部mask位i代表MSB坐标i，不能把它直接当numeric SIMON word的bit i。
未知round-key只记公开坐标的符号mask，从未代入真实key或key_seed，也未调用cipher evaluator。

| 反向round index | 生成非零路径 | 超变量限额输入路径 | beam丢弃 | 保留 |
|---|---:|---:|---:|---:|
| 5 | 4 | 0 | 0 | 4 |
| 4 | 52 | 0 | 0 | 52 |
| 3 | 13312 | 0 | 13248 | 64 |
| 2 | 6136 | 0 | 6072 | 64 |
| 1 | 63744 | 10 | 63680 | 64 |
| 0 | 27040 | 0 | 26976 | 64 |

生成合计110288个非零局部路径扩展（各层总和），这不是完整六轮路径数量。
`pruned_var`统计的是丢弃的输入路径数量，不能与`beam_discarded`直接解释成相同单位的遗漏谱质量。
各层同终点/key符号duplicates均0，只在本搜索保留前缀范围内成立，不是没有真实hull效应。
字典重量分布：5位1个、6位6个、7位14个、8位18个、9位15个、10位8个、11位2个。
保存编译耗时约0.700秒，仅本地编译，不是训练性能。

这些候选避开只枚举低阶1/2/3位字符的限制，但没有证据说它们是最佳mask、穷尽相关mask或能泛化。
mask选择完全依据公开结构、系数与预先确定的排序，不读取任何TRAIN/DEV/TEST标签，无事后目标位挑选。

## 下一步边界

这不是神经学习突破，而是确定了一个仍缺少相关性证据的结构字典。
若后续明确要求继续该路线，先另定**小型TRAIN-only相关性核查**预算和完整候选计数/多重比较处理，
只核已冻结的字典、配随机标签，不按结果加mask/beam或挑输出位；这仍需单独明确授权。
即使之后发现微弱相关，也不自动降低历史55%/3pp推进门槛，更不等价高精度位预测。
没有可泛化证据就不接新模型和GPU批次，避免把新机制名字当作扩算力理由。
