# 文档档案与指南索引

这里保存从 docs 根目录实际迁移的98份文件，正文逐字节不改；历史计划和许可不代表当前已执行或重新获准。**guides/ 中6份指南仍可阅读，归档位置不等于停用。**

[当前文档导航](../README.md) · [总 old→new 映射与 SHA256 清单（98份）](manifest-final.json) · [第一轮冻结快照（80份，不是总映射）](manifest.json)

两轮合并后的完整映射以 `manifest-final.json` 的 `path_index` 为准；旧 `manifest.json` 保持原字节，只记录第一轮独立迁移，不代表本轮最终布局。
旧报告、Superpowers、历史指南及正文中的旧路径不自动跳转，也不创建根目录 stub 或 symlink。
查找时先按原文旧位置解析相对路径，再在总清单的 `path_index` 中将旧仓库路径映射为新路径；查询串和片段锚点原样保留。
总清单扫描历史 Markdown 相对链接只核路径，不保证历史缺失文件或锚点可用，未声称旧链全部修复。
来源 JSON 内部旧 record 路径和其他引用未重写；旧 docs 路径查总映射，其他路径仍按其原有语义解析。
冻结的 result/、runs/、既存 validation/ 与历史原文不重写；仅指定活跃入口精确维护迁移路径。
