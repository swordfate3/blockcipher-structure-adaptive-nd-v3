# PRESENT-80 总7轮：遮挡补全能否辅助密文对分类？

**状态：已获用户批准。** 2个fit，物理GPU1、总协作墙钟1小时、一次限定Git发布/同步及前台运行，失败不重试。总轮数始终7，不重做中间状态选态，不外推到全轮或真实系统。

## 问题、对照与约束

实验要检验的是：给同一个 Shared-M 分类骨干多一个**只在训练时用的遮挡补全损失**，是否能改善原创新1组分类。两组均只使用公开缩减算法生成的合成密文，固定一把新80位合成密钥，训练与测试都不提供明文、中间状态、密钥或轮密钥给模型。正类差分 `0xD00000` 定义在明文端，负类端点独立均匀；两类同样完整加密7轮。每组4对，组内同类；TRAIN/DEV/TEST 为32768 / 8192 / 32768组、每个split正负各半。无序完整明文对跨split不重复；碰撞停止不重采。两臂共享同一面板、训练顺序及分类初值，fresh 独立训练，TEST共用且只构造一次。

| 臂 | 训练 | DEV / TEST |
|---|---|---|
| A 分类基线 | 完整C7，仅分类BCE | 完整C7，仅分类 |
| B 遮挡辅助 | 完整C7分类 + 同一个骨干上的遮挡补全，合在一次更新 | 完整C7，仅分类，不调用补全头 |

本次选择**同更新数上限的联合训练**而非预训练后再微调，因为容易回答“加一项训练信号是否有帮助”。B 每批多一次遮挡前向，参数多一个训练-only补全头；不称等算力或净算力收益，不加第三个算力匹配控制。普通完整预测值不作为分类输入，也不把补全称为“从明文预测绝对位”。无单独两轮预测器，不复用S2实验的数据或权重；旧52.3071%与理想S2的93.9819%只作历史背景，均非同期对照。

## 固定具体实现

- 两臂采用现有 C7-only Shared-M 完整输入表示与分类读出：6通道的前三通道为零、后三为左块/右块/同位XOR，4对各64位。参数初值按原seed31，分组 RNG 20261125、组排列 20261126，B追加补全头时不得改动或共享分类参数存储。
- **B遮挡视图**：每组每对从64个位置等概率无放回选16个，每个位置等概率只遮左/右之一；该位置的异或通道同时置零。前三通道仅在遮挡视图标示公开左掩码、右掩码、异或掩码，完整视图仍全零。掩码由公开种子20261127和B训练步号生成，不读标签、key或真实位值。模型只见遮挡后的位及掩码，原位仅由训练损失读取。其它特征只能由遮挡视图计算；没有完整视图特征旁路。
- B的一个训练步使用共享的stem/router/suffix参数，补全头从逐对逐位置特征预测被遮住的端点位（两通道，未遮住的位置不计补全BCE）；总损失 `分类 BCE + 0.1 × 被遮住位的平均 BCE`。每批仍只一次反传/同步优化更新。A和B使用同一既有父级 Adam/clip 实现；分别记录分类BCE与B的训练补全BCE，最佳epoch**只**按完整视图DEV组分类BCE选择，平局保留最早。batch128、最多30epoch、预热10/耐心8/min_delta1e-5，独立早停，FP32 Adam与原学习率设置保持。
- 评测前严格磁盘校验、恢复两份最佳权重；任一失败不生成TEST。TEST组准确率、正确组数、BCE、分类混淆矩阵和同组配对正确性四格（含B−A百分点）在一次成功终态提交。没有逐组预测落盘、原始明文/C7、key或中间状态输出。报告实际epoch、两臂前向及掩码量；只有一把key/固定种子，不外推显著性或可攻击性。
