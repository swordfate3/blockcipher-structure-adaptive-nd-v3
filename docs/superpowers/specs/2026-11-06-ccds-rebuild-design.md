## 3. 项目骨架与模块职权

```text
cipher-lab/
├── README.md
├── pyproject.toml
├── configs/                     # 少量精选完整配方
├── src/cipher_lab/
│   ├── cli.py                   # 解析、分派、展示退出原因
│   ├── config.py                # 严格解析及各方法的类型化设置
│   ├── ciphers/                 # 标量/向量密码运算与必要调度
│   ├── data/                    # 采样、划分、编码、标签与私有采集
│   ├── models/                  # 网络定义；非权重目录
│   ├── training/                # 优化、DEV选模和最终评价时序
│   ├── integral/                # 纯数学及积分方法的有限流程
│   ├── evaluation/              # 指标与checkpoint身份/严格加载
│   ├── execution.py             # 时钟、调用额度预留与停止
│   └── artifacts.py             # 序列化、来源身份、事件和产物引用
├── tests/
├── docs/                        # README及少量设计/计划
├── data/<run-id>/               # 唯一原始运行记录
├── models/<run-id>/             # 必要时的模型权重
└── result/<run-id>/             # 可读报告，不放原始数据或权重
```

只在对应功能有实现时创建目录；根 README 是唯一项目使用入口。维护设计与实施计划各一份，审查默认留在会话，不每个任务新增审查文档树。

依赖约束：
- CLI → 设置加载 + 已实现科学方法入口；采用小范围显式分派，不动态导入/注册插件。真正新增科学方法允许改分派；仅修改配方不得改分派。
- 科学方法 → 数据/模型/数学/评价/执行限制/保存；CLI不承载循环或研究决策。
- 密码 → NumPy/标准库；不读实验设置、模型或报告。
- 数据 → 密码与公开编码；私有key/背景/标签生成在此封装，模型与符号认证层不接触实际秘密。
- 模型 → Torch和无秘密公开表示；不读标签、密码内部状态、配置文件或运行产物。
- 纯积分数学 → 显式输入的位掩码/聚合行/公开结构；不采集、不读文件、不决定选项和授权。
- 执行限制与保存 → 通用技术输入；不决定科学选模、候选、阶段晋级或结果含义，不导入科学方法。
- 评价不反向依赖训练；报告只读取公开保存结果，不触发采样、前向、加密或新指标计算。

`training/`里的通用优化更新与两个任务的组装/选模策略分开；不能合并不同科学标签时序。`integral/`中的经验发现与认证分开，经验通过不标成数学证明。不同停止原因、调用单位必须保留科学含义，不能用一个无定义的count字段覆盖。

## 4. 三类变化的明确归属

| 变化 | 归属 | 示例 |
|---|---|---|
| 算法或科学方法 | 源码 + 测试 | 新模型、精确ANF算法、确认顺序、不泄露TEST的规则 |
| 科学配方 | 完整实验设置 | rounds、活跃位集合、分阶段组数、batch、学习率、模型规格 |
| 当次执行限制 | 执行策略输入 | 设备、调用上限、wall/CPU、截止时刻、内存/输出上限 |

固定观测项的定义/位序/一致性校验留在算法；配方参数受其支持范围验证，并非任意JSON都可运行。阶段顺序与数据隔离由方法代码固定，不提供任意阶段脚本执行。

配方必须完整且版本化，不做多层继承、不用环境隐式覆盖、不读取其他实验目录。变化通过一份设置表达，不预先展开几十份排列组合JSON。运行前解析成规范快照，保存有效设置和执行策略；同一数据不重复序列化成多份事实源。

执行策略可由命令行或单独的小JSON提供（具体字段名交实施设计）；策略只描述限制，不凭文件自授予科研权限。缺必要许可时由操作流程阻止启动。默认不重试/续跑；旧授权不带入新项目。协作式检查不是OS硬限，报告必须说明。

## 5. CLI及运行生命周期

以下为拟实现接口，尚不可用：
- `check`：严格检查配方、执行限制和可用设备；不生成数据、不调用密码、不加载训练模型、不创建run。
- `run`：申请全新run-id输出位置 → 保存设置/源码身份 → 固定方法执行 → 写终态和公开摘要 → 生成可读报告。
- `evaluate`：阶段1不注册；训练能力以后接入时才提供。其契约为显式checkpoint + 显式、身份可校验的评价数据集，输出新的评价记录；不从公开seed恢复真实key，不默认重新加密。训练方法是否导出可复评输入/标签由后续设计明确选项与存储范围；未导出就不得承诺可复评原TEST。评价新面板需要另行获准采集并记录新身份。积分不提供伪checkpoint评价；保存结果的报告渲染不调用evaluate。

输出run-id使用保守字符集合、禁止路径穿越；同编号占用时拒绝覆盖。开始真实调用前完成所需目录的独占申请，部分申请失败只回收本次新建空目录，禁止触碰既有目录。数据调用前预留预算，attempted/completed与单位各自记录。失败尽力保存状态，不自动清除证据；强杀缺终态视为UNKNOWN。

## 6. 必要产物与生命周期

一个run-id关联三个物理位置，但只存一套科学数据，不做报告副本：

```text
data/<id>/
  run.json                # 设置、执行策略、源码/环境身份、来源、终态、计数、摘要、产物引用
  events.jsonl            # 追加进度；含失败公开原因；不重复整份run快照
  payload/                # 仅方法确需的聚合行、证书或缓存；按需创建
models/<id>/
  best.pt                 # 仅训练；是否last或恢复态需具体需求，不默认多存
result/<id>/
  report.md
  index.html
  source.json             # 引用run身份、报告输入SHA，不复制原始账本
```

`run.json`生命周期中原子更新，终态后不可改写；`events.jsonl`单向追加。原始科学载荷写完即冻结；后续报告不改原始数据。报告默认运行终态时生成，失败亦说明失败；报告失败不得篡改已完成的科学状态，CLI明确区分二者。仅报告重绘允许读取保存摘要/载荷，不重算科学指标。

秘密不进入事件、报告、run设置快照与checkpoint；实际秘密或可还原它的私有seed不输出。公开模型初始化/明文采样seed与私有密钥随机源独立，禁止公开一个总seed间接恢复全部秘密。输入/标签数据不等同于密钥，未来若为复评导出，留在非网页服务的数据目录且不得作为额外模型输入；首期不保存逐点密文或此类复评数据集。逐点密文仅瞬时处理；积分保存必要公开聚合值/认证材料。若研究需要跨进程再生成私有数据，须另设计私有材料保管，不声称当前默认产物可完全重放。源码/环境身份是来源记录，不是独立可信证明。

数据和模型不进Git；结果按现有项目约定不提交大载荷或秘密。静态预览只服务result/，不能通过../链接暴露data/models；来源引用为受约束项目相对标识而非可下载链接。HTML内联图或自身图片，不依赖原始数据目录。报告保留方法图与已有结果图；无科学结果时不伪造结果图。

临时测试用pytest临时目录，由测试清理。只在昂贵步骤确需时缓存，有明确消费者；不预建validation/outputs/runs或每任务检查副本。删除实际运行资料须另列清单获准，不自动按年龄删负结果。每增加一种永久文件，须说明用途、消费者与保留规则。

### 10.2 数据与方法的不可变语义

**位预测**：方法`bit-prediction-v1`，SIMON64/128，full64位明文输入，绝对密文MSB0目标bit，MLP输出一个logit。模型只含两层可配置等宽ReLU隐藏层，首版不接support/residual/旧结构候选。rounds1..44、target_bit0..63、hidden_width及TRAIN/DEV/TEST行数、batch/epoch/lr可配置。真实分支单次run一把私有随机128bit固定key；null分支独立随机bit，二者作为显式配方分别run而不是自动扩大实验。公开采样/初始化/shuffle种子与私有密钥随机源独立，公开总seed不能恢复key。

数据层先准备无重复输入及TRAIN/DEV标签；每epoch DEV BCE严格更低才选模、相等保最早；严格加载选中的新checkpoint后才访问/生成TEST标签。最终TRAIN/DEV/TEST指标用已选模型明确计算，报告渲染不再前向。基线只用TRAIN拟合多数类/平滑概率，报告准确率与BCE；不把单key结论称跨key泛化。

**创新1**：方法`shared-m-four-task-v1`，固定支持四种密码族，任务声明在配方单点列出，不在训练器重复任务字面量。默认SIMECK64/128 r16 Δ0x40、PRESENT80 r7 Δ0xD00000、SIMON64/128 r13 Δ0x40、SKINNY64/64 r8 Δ0x2000。顺序固定四任务，各轮数与非零差分可在密码合法范围改设置；其他任务族不是本期可选项。

每decision恰4pair/8块、组内同key，正例P与P XOR Δ，负例独立明文的真实加密；不能负例直接随机密文。各split每任务偶数groups，正负平衡；私有key各组新生成，不能从公共seed派生。输入为[B,4,2,64]二进制，标签[B,1]，public13卡只描述密码公开结构，不能读取ciphertext/key/label。卡校验移到无密码调用的公开表示模块，模型不依赖ciphers包。SKINNY的无秘密public backstep作为公开表示，不包装真实密钥接口。独立检查发现旧函数固定第8轮常数；新实现明确接收任务的公开rounds参数（不增加/改变public13路由输入），只将末轮公开常数递推到该轮，其余key-free部分逆变换不变，r8必须与旧公开变换人工向量逐项一致。模型forward除public13还接收公开TaskSpec/rounds用于表示，router仍只看public13。任务声明的rounds和差分同时绑定checkpoint与TEST bundle，evaluate默认拒绝与checkpoint训练任务声明不一致的任务，以免误用公开表示。这个泛化是明确的公开表示变化，来源记录说明；不声称已做真实非8轮密码验证。

模型保留shared-M主方法：local/word/nibble三stem、public13 learned top2 router、共享五个残差后缀与pair readout，默认1,087,509参数为结构验收项；三个stem主网络同初值、relation projection零初始化。只接single/relation/pair/learned这一条，不迁入dual/fixed-route/旧兼容选项和未使用的旧惩罚接口。stem/channel/norm/head宽度、奇数kernel列表等模型尺寸可按合法约束配置，语义不变。

每宏batch四任务各优化一步，单joint模型；BCE+gradient clip1、Adam，不凭空添加aux惩罚。所有split数据预建，TEST只在DEV选模及严格加载后评分；如实区别于位预测的延后TEST标签时序。每epoch四任务DEV BCE等权均值选模，严格下降/最早平局；最终逐任务ACC/BCE与平衡基线，不与位预测合并准确率。

### 10.3 模块职责和依赖

- 新`models/`只定义MLP、shared-M参数与前向，`representations/`只处理无秘密公开卡/邻域/输入表示；均不导入data/config/training或读取run。
- 新数据模块分别拥有位预测固定key/标签时序与四pair差分组构造，消费密码适配器和预算，向训练只返回所需tensor和公开任务信息；密钥/私有RNG状态不导出。
- `training/`共享优化单步、批次评价和严格DEV选择的基本操作；位预测及四任务方法只做必要的组装/时序，不各造保存/时钟/JSON/optimizer实现。不要为了“统一”允许任意callable阶段图。
- `evaluation/`拥有指标与checkpoint严格加载/模型规格验证；不导入training或采集。显式evaluate不import ciphers、生产随机源或data生成器。

### 10.4 checkpoint与独立evaluate

只保存一个best checkpoint，正常DEV更优时允许同owner原子替换best、同步当前引用SHA；不默认存last/optimizer/resume副本。checkpoint是新schema，只有公开模型规格、CPU tensor state、选模epoch/updates、recipe身份引用、TRAIN基线等必要公开信息；不包含密钥/私有seed/数据RNG或旧完整配置。`torch.load(weights_only=True)`，大小上限256MiB、SHA先验证、字段白名单、形状/dtype/layout/有限值/持久接线严格检查，拒绝未知模型和旧checkpoint。

每次训练默认只导出**最终评价的TEST输入/标签**一份（创新1四任务各一份，附public卡与任务声明）；TRAIN/DEV只留必要身份/指标，不默认全部复制。数据导出在各自正确访问时刻以后，不提前生成位预测TEST标签；标签数据不含密钥或私有seed，也不作为额外模型输入。不再声称仅靠默认记录可以重采相同私有key。

`evaluate`拟接收显式checkpoint路径+SHA、显式数据bundle路径+SHA、输出root/run-id、执行限制；只在新项目支持的模型与数据schema下运行已有TEST数据，产生新的运行记录/报告，不重新采样或加密。同一输入从训练再评价时指标应匹配，但这是用户主动evaluate，不由报告/结果取回自动触发。数据必须与model method/输入规格/任务卡一致，run级数据身份单独记录；评价不同已保存面板合法但明确新来源，不冒充原TEST。

数据bundle使用非pickle的明确二进制格式（例如NumPy NPZ的allow_pickle=False、逐数组schema/大小/形状/类型/值域/摘要；具体规范交计划固定），加载前压缩与解压尺寸/条目上限，不能让仅小压缩文件绕过内存限制。path引用无`../`，models/data不会作为HTML下载暴露。
