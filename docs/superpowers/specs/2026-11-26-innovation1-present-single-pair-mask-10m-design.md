## 科学配方

- 继续上一批原明文端定义的任务：正类为固定明文差分 `0xD00000`，负类为独立随机两端，两类同样用合成密钥完整加密7轮。所有划分、两臂共享唯一一把新合成80-bit key。数据提供者不向模型提供明文、key、轮密钥或中间状态；只物化 C7。独立模型和优化器，同样的初始分类器参数。
- 新固定 TRAIN / DEV / TEST 分别为 **5,000,000 / 32,768 / 131,072 对**；各自正负各半。完整无序对跨 split 不重叠，发现碰撞停止、不重采；同一对在不同 epoch 重放不算新增样本。每对 `(C,C')` 对应一个标签和一个分数，不合组判分、不用密文单条作分类样本。公开采样/排列/分类器初始化/掩码 seed 沿用 `20261125/20261126/31/20261127`，新配方身份独立。
- A 只在完整 C7 视图上做分类。B 同样做完整 C7 分类，并额外用遮挡视图、同一骨干做补全。同批反向只一次，目标 `分类 BCE + 0.1 × 隐藏位 BCE`。每对无放回取16个位置、每位置只遮一侧及同位 XOR；掩码不依赖原值或标签，完整视图前三个标记通道恒零，遮挡视图重算特征，无明文/中间状态/完整特征旁路。辅助头只在 B 的 TRAIN 运行。DEV/TEST 都是完整视图，每对独立。
- 复用前一批 FP32 Adam、Shared-M 公共卡/骨干/单对读出部件；**没有四对均值**；临时四槽仅允许作等价的张量执行布局，不能汇合、归一化或复制不同样本。batch **512对**；训练每轮9,765个整批＋1个尾批320对，全部保留。A/B 各恰30个完整 epoch，资源或故障不足则 STOP/FAIL，**禁科学早停**。每个 epoch 做一次完整 DEV，分类 BCE 严格最低选 best，平局保留最早；按实际对数加权记录训练指标和补全指标，不把尾批当512对计数。
- 两份 DEV best 严格磁盘 SHA/域身份/缓冲区/权重恢复后才生成唯一共同 TEST。两臂的正确对数/131,072、BCE、二元混淆矩阵及同对正确性四格/B−A 百分点差，一次随成功终态提交。TEST 原值、逐对 logits、P、C7、key 均不归档。单独记录每臂 actual epochs、best、更新、分类和辅助前向；B 有额外计算，不称等算力增益。上批四对组分数不是本批对照。扩大样本不自动证明跨密钥可重复。
