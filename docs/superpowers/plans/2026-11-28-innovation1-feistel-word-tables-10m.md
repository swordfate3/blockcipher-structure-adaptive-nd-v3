# SIMECK 与 SIMON 专属字表实施计划

从全量有卡提交 `a0288e9` 建立独立分支。SIMECK 与 SIMON 分别按已确认顺序编译 64×9 字表。两张卡描述 MSB0、32 位字内回绕、中心槽位及跨字对应槽位。完备校验包含表摘要和固定 checkpoint 缓冲区。

- [ ] 先验证字边界上的索引、历史有卡配方等价、相同初始参数、Top‑2 字表选择及严格重载。
- [ ] 将表编译接入全量配方与现有共享模型。逐轮、最佳和重载记录保存 `word_lookup`。复用全量读取器、优化和早停规则。
- [ ] 验证旧配方的 CLI 输出、定向回归、Ruff、mypy 与独立审查。发布独立分支。
- [ ] 核实前置撤卡运行结束，按 GPU0、30 epoch、16 小时协作预算启动一次。

实验以原全量有卡组为对照。其四项数据池各含 900 万 TRAIN、100 万 DEV、262,144 对 TEST。本轮新增两个固定缓冲区，继续共享全部 1,087,509 个可训练参数。
