# 回到神经学习：公开硬布尔前向＋STE

## 任务归位

用户澄清代数/SAT不是神经学习，并明确差分bit预测暂缓。
本轮只做原任务：固定key，明文P→SIMON预定目标bit0；不生成差分数据集。
旧硬枚举r4成功/SAT r5UNKNOWN保留，但不把它们记为神经轮数成果。

新增`model_kind=simon-ste`，公开依赖DAG和未知常量参数，**通过TRAIN BCE反向传播、Adam更新**。
不调用SAT、枚举、坐标离散搜索、历史解或真实key初始化。
这是可微结构/逻辑网络的梯度学习候选，不是通用MLP，也不是全key恢复目标。

## 明确算法

每个未知符号坐标一个实数theta；q=sigmoid(theta)，h=1[theta>0]。
用`h+(q-q.detach())`作硬前向的STE叶子：数值为0/1，反向使用q的导数。
公开AND使用ab，XOR使用a+b-2ab，均在硬前向状态上运算。
输出p仍为0/1，logit=2*(2*p-1)，即±2；不把硬p送进log/clamp（否则梯度可截断）。

- train/eval均硬前向，模式不会偷偷改变预测函数；hard_constants与主指标应相同。
- 后向是有偏替代梯度，不是真正离散函数导数，也不是软图导数。
  隐含层的多项式导数在硬状态上求值，不保证存在下降方向或找到正确常量。
- init17随机±2加小扰动后整体乘.05，故初始约±.1；与真实key/标签无关。
- 参数仅key_logits，无额外head；r1=1、r3=11、r4=24。
- 固定±2意味着正确样本BCE约.126928，错误约2.126928，不能把其概率称校准置信度。
  DEV BCE选模与DEV准确率等价，数值微差仍可能由浮点归约产生；沿用严格小于时更新的规则。

## 本轮执行合同（真实拟合前固定）

本机CPU、无GPU/SSH/安装/commit/push，每项最多120秒协作预算，不是硬进程截止。
`configs/innovation2-ste/`：smoke、r1、r3、r4、r4-null。

真实项TRAIN4096/DEV1024/TEST8192，data192001、key190502、init17、null191402。
batch256、50epochs、800实际梯度更新、204800presentations，Adam.01、clip1。
每项一次，不追加seed/epoch、重启、搜索分支或提升预算。

1. 工程测试与干净源码null2更新check/train/evaluate。
2. r1真实正控，TEST≥99%才继续r3；公开参考常量基线本就100%，不要求优于它。
3. r3需TEST≥70%，并且TEST BCE优于TRAIN固定概率与公开参考残差常量两类基线，才继续r4。
4. r4需同样≥70%且BCE优于两类基线，才做一次r4-null。若未通过，不启动后续。
5. 本批不自动试5轮；先确认3/4轮神经梯度有效，而不是因为枚举成功就跳正控。

只有TRAIN用于更新，DEV选择checkpoint；严格加载选中checkpoint后生成TEST标签。
跨轮使用TEST门槛属于探索性推进，不称独立封存确认；不做TEST后挑位或改超参数。
单key/seed、不同旧实验面板不称公平方法对比；若有信号后续需同期MLP/null及独立面板确认。

## 完成与失败的解释

工程梯度有限/人工最小XOR学会，不意味着真实r3/r4成功；只以实际保存指标报告。
若正控失败，说明当前STE参数化与固定训练设置未学到，不证明所有硬前向逻辑网络无效。
