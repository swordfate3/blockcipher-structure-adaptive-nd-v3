# 轮展开候选：单轮学习控制与浅轮定位（执行前计划）

本批响应用户“继续推进”，保持main及现有未提交工作，不合并/更改保存的其他分支。
上一批r3约50%已关闭，不重跑该批，不加载其checkpoint或重新评价旧模型。
本批不改模型、训练、评价、配置schema或优化语义，只补新配置与控制测试。

## 问题和预期判别

上一批欠缺局部规则学习正控。本批分开测：
1. 同一神经模块能否用梯度拟合公开单轮局部规则？
2. 随机无关明文位存在时，一轮最终单bit能否学会？
3. 一轮能学会而两轮失败，是否定位到端到端组合学习问题？

一轮成功不证明所有轮状态正确。两轮失败也不唯一指向梯度消失：
共享cell/连续标量瓶颈/未知条件耦合/训练预算均可能有关。本批不扫描这些因素。

## A：人工公开规则控制（不是密码成绩）

`tests/test_unrolled_simon_learning_control.py`使用同一个
`UnrolledSimonPredictor(width32,rounds1,target0)`，从init17随机初始化。
输入覆盖(y,a,b,c)全部16种角点，填明文坐标[32,1,8,2]，其余位置0。
标签为公开人工函数 `y XOR (a AND b) XOR c XOR z`，z分别固定0、1。
无真实cipher/key/中间轨迹调用。每个z独立初始化；Adam .01/clip1，1000个全表更新，
每次16行，共16000次呈现；最终全表ACC100%且BCE<.05为通过。
不把z写入模型参数；只经公开人工标签学习。没有独立持出角点，故只说明训练拟合，
不证明泛化或密码预测。完整测试套件可能重复执行该确定性工程控制，不作为新增科研seed。
不改变步长/更新数补救失败；若任何一个z失败，则不启动B。

## B：新面板浅轮真实/null（最多四项）

使用既有统一CLI `cipher-experiments check/train/evaluate`；正式运行仅check/train。
配置位于`configs/innovation2-unrolled-local/`：r1真实、r1-null，以及门槛通过才跑的r2真实/r2-null。

共同固定：CPU，SIMON64/128，MSB bit0，full/direct，simon-unrolled，width32；
TRAIN4096/DEV1024/TEST8192，batch256/50epochs，Adam .001/clip1；
data192701/key190502/init17/null192702；800更新/204800次呈现/项，120秒协作预算/项。
最多3200更新/819200次呈现/480秒协作预算，不是硬截止。
与人工全表相比，真实任务增加无关位及随机抽样，学习率与呈现预算也不同；
因此二者有差异时不能单独归因于无关位。

r1真实与null都执行；仅当r1真实**DEV ACC≥99%且DEV BCE<.05**才执行r2真实与null。
一轮公开参考残差基线理论上已可从TRAIN学到全正确，故不要求神经模型胜过该基线，
也不把一轮神经成功称密码分析优势。DEV选模；推进仅用DEV，TEST最终一次报告。
两轮即本批终点，无自动r3/4/5、无超参或seed追加、无旧checkpoint预训练。

真实key只供数据层最终输出bit标签生成，不给模型真实轮密钥或状态；
两轮训练也只用两轮最终bit标签，不额外喂一轮标签、不迁移r1权重。
真实/null同轮同面板同初始化，最终checkpoint严格加载后才生成TEST标签。
