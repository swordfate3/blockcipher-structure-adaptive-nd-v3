## 结论

固定公开目标DAG、32维类型化乘性门与半径2投影的首批六轮实验已完成。**未得到可靠的六轮预测改善，也未观察到明显TRAIN拟合。**

预定的描述性DEV条件确实满足，必须如实保留；但这不等于可靠信号或科学突破，不自动启动确认。

一个重要警示：真实selected模型在TRAIN/DEV/TEST的正确数，分别恰好等于该split的bit1标签数；这与“始终预测1”的准确率完全一致。

### 为什么不能把DEV条件满足说成突破

原合同的描述性规则是：真实DEV BCE低于TRAIN常量、DEV ACC同时高于常量和null。这三项在本批为真，冻结记录没有改写。
但真实TRAIN多数是0，DEV略偏1；selected真实准确率刚好等于各split的bit1比例：

| split | 保存正确数 | bit1标签数（由TRAIN常量bit0的保存准确率与样本数反推） |
|---|---:|---:|
| TRAIN | 32525 / 65536 | 32525 |
| DEV | 4140 / 8192 | 4140 |
| TEST | 32879 / 65536 | 32879 |

这不是新的标签构造，也不是逐样本预测验证。它说明这条非常宽松的DEV描述性规则可被类别比例与输出偏置解释，不能识别“是否真正使用输入”。
本批不临时改门槛为95%或55%，也不追溯把规则记为失败；结论是**描述性规则满足，但证据不足以支持有效输入条件预测**。
没有预定显著性检验，不能把8次DEV选择后的微小差异称统计证据。TEST也是探索旁证，不是封存独立确认。
